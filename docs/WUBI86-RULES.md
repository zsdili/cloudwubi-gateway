# 云五笔 86 版打字与显示规则（权威版）

> 依据：ima（百度五笔方案）、Kimi（百度五笔规则）、元宝（输入法联想原理）三大 AI 权威梳理 + 86 版王码五笔官方规则 + 本地真实引擎 90+ 场景回归验证。
> 版本：v0.7.11（2026-09-16 云端生效）

## 一、单字编码规则（86 版）

| 汉字类型 | 取码规则 | 示例 |
|---|---|---|
| 键名汉字 | 连按所在键 4 次 | 王 GGGG、土 FFFF、言 YYYY、水 IIII |
| 成字字根 | 报户口 + 首笔 + 次笔 + 末笔 | 士 FGHG、雨 FGHY、石 DGTG、马 CNNG、耳 BGHG |
| 单笔画 | 所在键×2 + LL | 一 GGLL、丨 HHLL |
| 键外字（≥4 根） | 取 1、2、3、末字根 | 赣 UJTM（立早夂贝） |
| 键外字（<4 根） | 取全部字根 + 末笔识别码 | 沐 ISY（氵木+捺左右）、码 DCG（石马+横左右） |

**末笔识别码**：末笔定区（横1 竖2 撇3 捺4 折5）× 字型定位（左右1 上下2 杂合3）。
例：沐 ISY（末笔捺4=Y 区，左右1=Y 位）；音 UJF（末笔横1=F 区，上下2=F 位）；吧 KCN（末笔折5=N 区，左右1=N 位）。

**五大区键位**：横 GFDSA / 竖 HJKL M / 撇 TREWQ / 捺 YUIOP / 折 NBVCX。

## 二、词组编码规则（按全码取码，不是简码！）

| 词组字数 | 取码公式 | 示例 |
|---|---|---|
| 二字词 | 前字前 2 码 + 后字前 2 码 | 北京 UXYI、可以 SKNY、乐意 QIUJ、谢谢 YTYT |
| 三字词 | 前两字各首码 + 第三字前 2 码 | 计算机 YTSM、没办法 ILIF、为什么 YWTC |
| 四字词 | 各取首码 | 五笔字型 GTPG、操作系统 RWTX |
| 多字词（≥5） | 前 3 字首码 + 末字首码 | 中华人民共和国 KWWL、中国人民解放军 KLWP |

**铁律**：
- 词组编码一律用**全码**取首码/前 2 码，**不用一级/二级简码**。例："不"全码 GII → "不等于"=G+T+GF=GTGF（非 ITGF）；"为"全码 YLYI → "为什么"=Y+W+TC=YWTC（非 OWTC）。
- 一级简码只在**单字 1 码输入**时生效（打 r 出"的"）。

## 三、简码系统（单字）

| 简码 | 规则 | 示例 |
|---|---|---|
| 一级简码 25 字 | 1 码 = 高频字（口诀：一地在要工，上是中国同，和的有人我，主产不为这，民了发以经） | 打 R → 的（第一） |
| 二级简码 | 前 2 码 = 常用字 | 打 SK → 可 |
| 三级简码 | 前 3 码 = 常用字 | 打 SUF → 栏 |

**优先级**：一级简码 > 二级 > 三级 > 全码（同码时简码字排在前面）。

## 四、候选显示排序规则（已固化）

| 输入码长 | 排序规则 |
|---|---|
| 1 码 | 一级简码字最前（打 r=的、i=不、p=这）→ 字根字 → MRU 上屏字 |
| 2 码 | 高频单字最前 → 二字词 → MRU 置顶（上次上屏的字/词永远第一） |
| 3 码 | 三级简码单字优先 → 前缀单字 → 词组 → 预测第 4 码高频词组 |
| 4 码 | **全码精确匹配字置顶**（键名字 GGGG→王、RRRR→白）→ 词组（端侧词组先单字后）→ 云端词组 |

**铁律**：
- 4 码输入时，精确全码字（键名字/全码字）**必须第一**，不得被高频字/词组字压后。
- 上次上屏的字/词**永远置顶**（MRU 写死规则），除非有同码新字词上屏。
- 严禁把联想句子放在最前面（仅限补全时可选）；严禁出现繁体字。

## 五、联想原理（元宝共识，供后续增强）

- 联想本质 = 预测"下一个语言单元"：P(下一个字/词/句 | 前面已输入)。
- 三代技术：n-gram（前 2~3 字固定搭配）→ 神经网络（整句跨句语境）→ LLM（整段对话+场景）。
- 工程实现：音字转换（维特比解码 + 语言模型打分）+ 端云协同（端侧小模型毫秒响应、云端大模型深度语义）。
